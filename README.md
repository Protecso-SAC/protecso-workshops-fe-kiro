# protecso-workshops-fe-kiro

Presentaciones de la capacitación de Kiro de Protecso. Son archivos HTML
autocontenidos: no necesitan instalación, servidor ni conexión a internet.

| Archivo | Contenido | Diapositivas |
| ------- | --------- | :----------: |
| `index.html` | Introducción a Kiro | 12 |
| `nivel-1.html` | Nivel 1: chat, contexto y cambio pequeño | 10 |
| `nivel-2.html` | Nivel 2: steering, specs y revisión | 9 |
| `nivel-3.html` | Nivel 3: hooks, MCP, agentes, Kiro Crew y adopción | 13 |

## Cómo usarlas

Abre el archivo en un navegador. Se navega con las flechas del teclado.
Para ir a una diapositiva concreta, usa su ancla en la URL, por ejemplo
`nivel-1.html#3`.
